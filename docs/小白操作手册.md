# AI-KM 知识管理平台 · 小白操作手册

> 适用对象：第一次使用本系统的普通同事（非技术人员也看得懂）
> 文档目标：照着做，5 分钟就能查资料、问 AI、传文档、做审核
> 适用版本：AI-KM v1.0（本地版 / 内网版通用）

---

## 一、这是什么？能帮我干什么？

AI-KM 是公司内部的**知识管理平台**，把分散在微信群、邮件、电脑里的政策、项目、客户、产品、流程、培训资料，统一收拢成一个"公司大脑"。

你平时能用它做四件事：

| 你会用到的功能 | 解决什么痛点 | 入口 |
| --- | --- | --- |
| **查资料** | 想找一份政策/制度，不用翻聊天记录 | 检索页 |
| **问 AI** | 不想自己读长文档，直接问，AI 帮你读并给答案+出处 | 问答页 |
| **传资料** | 手上有好文档，上传进来让所有人都能用 | 入库页 |
| **审资料**（部分同事） | 别人的文档质量把关，通过或退回 | 审核页 |

> 【提示】系统里所有回答都**必须基于已入库的资料**，AI 不会"编故事"。如果资料里没有，它会老实告诉你"没找到"，并提示你去补充。

## 二、第一次怎么打开？

### 1. 打开浏览器，输入地址

- **本地自己电脑跑**：在浏览器地址栏输入 `http://localhost:5200`
- **公司内网服务器**：输入 `http://192.168.0.61:5200`
  （具体地址以公司通知为准）

### 2. 登录账号

系统第一次启用时，管理员已经建好了初始账号：

| 项目 | 内容 |
| --- | --- |
| 用户名 | `admin` |
| 初始密码 | `Admin@123456` |

> 【重要】**第一次登录会被强制要求修改密码**（系统自动跳到「修改密码」页），改完才能进入系统。
> 日常想改密码，点左侧菜单「🔑 修改密码」即可。把初始密码发给别人是很危险的。

如果你没有账号，找你们部门的系统管理员（或 IT）帮你开一个。

## 三、界面长什么样？（先看全局）

登录后，你会看到顶部一条**导航栏**，从左到右是：

```
知识检索   智能问答   知识入库   审核台   效能看板   [管理后台，仅管理员可见]   右侧：当前用户名 + 退出
```

- 左边是**主功能菜单**，和顶部导航一一对应。
- 中间是**工作区**，点不同菜单切换不同页面。
- 右上角一直显示**你是谁**，点它能退出登录。

> 【提示】不同角色看到的菜单可能不一样。普通同事通常只能看到"检索、问答、入库"；审核员多一个"审核台"；管理员才有"管理后台"。

## 四、角色与你能看到什么

系统有四类角色，权限从低到高：

| 角色 | 能干什么 | 通俗解释 |
| --- | --- | --- |
| **普通用户** | 查资料、问 AI | 只读，用知识的人 |
| **贡献者** | 查、问、上传资料 | 往系统里"喂"资料的人 |
| **审核员** | 以上 + 审核别人传的文档 | 给资料质量把关的人 |
| **系统管理员** | 以上全部 + 管用户/密钥/日志/评测 | 平台的"总管家" |

> 【注意】**机密**级别的文档，只有被授权的同事才看得到。如果你搜不到某份机密资料，不是系统坏了，是权限不够，找管理员确认。

## 五、第一步：检索知识（查资料）

### 操作步骤

1. 点顶部导航 **「知识检索」**（或左边菜单）。
2. 在搜索框输入关键词，例如：`高值耗材 集采`、`项目立项流程`。
3. 点搜索框右边的 **「搜索」** 按钮（或按回车）。
4. 看结果列表：
   - 每条结果显示**标题、所属分类、密级、相关度**。
   - 命中的关键词会被**高亮**（标黄）显示，方便你快速扫读。
5. 点任意一条结果，跳到**文档详情页**，看完整原文和出处信息。

### 进阶筛选（结果太多时）

搜索框下方有几个下拉框，可以缩小范围：

- **检索模式**：默认"混合"（又看关键词又看语义，最准）；也可以切"仅关键词"或"仅语义"。
- **一级分类**：比如只看"政策法规库"或"客户与市场"。
- **密级**：比如只看"公开"或"内部"资料。

> 【提示】搜不到东西时，先确认是不是筛选项设太窄了；再试换个说法（比如"集采"搜不到，试试"集中带量采购"）。

---

## 六、第二步：问 AI（让 AI 读资料后回答）

### 操作步骤

1. 点顶部导航 **「智能问答」**。
2. 在底部输入框，用**大白话**提问，例如：
   - "集采政策对我们医院采购有什么影响？"
   - "项目验收需要准备哪些材料？"
3. 点 **「发送」**（或回车）。AI 会**一个字一个字流式**地把答案打出来。
4. 答案里带 **[1] [2]** 这样的角标，就是引用了哪份资料的哪段内容。
   - 点角标可以**跳到对应原文片段**，方便你核对出处。
5. 可以继续**追问**：比如"那未中选产品怎么处理？"——AI 会结合上文接着答。

### 你可以做什么

- **开新对话**：点「新对话」按钮，清空上下文，开始一个全新话题。
- **看历史**：左侧有历史会话列表，点回去能接着聊。
- **给反馈**：觉得回答有用点「👍」，没用点「👎」——你的反馈会帮助系统越用越准。
  （注：若反馈按钮未显示，不影响使用，可忽略此条。）

### 常见情况

- **AI 说"资料库中没有相关信息"**：说明目前没人上传相关资料。你可以去「知识入库」把对应文档传上来，之后就能问到了。
- **答案看着不放心**：一定点引用角标回看原文，AI 是基于原文生成的，原文为准。

> 【重要】AI 的回答**仅供参考、以原文为准**。涉及合同、合规、金额等关键决策，请回到原始文档或找负责人确认，不要只凭 AI 回答做决定。

## 七、第三步：上传知识（把资料存进公司大脑）

> 本功能需要你是**贡献者 / 审核员 / 管理员**身份。

### 操作步骤

1. 点顶部导航 **「知识入库」**。
2. 填表单（带 * 的是必填）：

| 字段 | 填什么 | 说明 |
| --- | --- | --- |
| **标题 \*** | 文档标题 | 建议用统一命名：`[地域/主体]+[时间]+[主题]+[类型]`，如"2025国家高值耗材集采政策解读" |
| **一级分类 \*** | 下拉选 | 六大类之一（见下方说明） |
| **二级分类** | 下拉选 | 选了上级后自动出现，如"国家级政策" |
| **所属部门 \*** | 下拉选 | 这份资料归属哪个部门 |
| **密级 \*** | 下拉选 | 公开 / 内部 / 机密（见下方密级说明） |
| **质量等级** | 下拉选 | 默认"常规"；确定无误可标"已验证高质量" |
| **负责人 \*** | 填名字 | 这份资料的对接人，出问题找谁 |
| **生效日期** | 选日期 | 资料开始有效的日期 |
| **失效日期** | 选日期 | 资料过期日期（政策类建议填） |
| **来源** | 填文字 | 出自哪里，如"国家医保局" |
| **摘要** | 填文字 | 一两句话概括，方便别人快速判断 |
| **文件 \*** | 选文件 | 见下方支持格式 |

3. 点 **「选择文件」**，选中要上传的文档。
4. （管理员/审核员可见）如需**跳过审核直接发布**，勾选"跳过审核直接发布"。
5. 点 **「提交入库」**。

### 支持的文件格式

- Word：`*.docx`
- PDF：`*.pdf`（扫描版图片 PDF 可能无法提取文字，建议用可复制文字的版本）
- Excel：`*.xlsx`
- 笔记/网页：`*.md`、`*.html`
- 纯文本：`*.txt`

### 提交后会发生什么？

文档会经历一条"流水线"：

```
已上传 → 解析中 → 已解析 → 待审核 →（审核员通过）→ 已发布
                                              ↘（审核员退回）→ 已退回
```

- 你提交后，状态变成**「待审核」**，需要审核员通过才会正式对外可见。
- 如果被打回（**已退回**），系统会写明退回原因，你改好后重新提交即可。
- **管理员/审核员**勾了"跳过审核"的，会直接变成**「已发布」**，所有人立即可见。

> 【提示】上传成功后页面会显示"文档 ID"，记一下方便后续查询。

## 七-二、在线编辑文档（富文本，像写 Word 一样）

已发布/待审核的文档，点开详情页右上角「✏️ 编辑」即可在线修改，**不用重新上传文件**：

- **富文本排版**：工具栏支持标题、加粗、斜体、下划线、列表、引用、代码块、链接，所见即所得。
- **图片直接贴**：截图后 `Ctrl/Cmd+V` 粘贴，或把图片文件拖进编辑区，会自动上传并显示（不用先存本地再插入）。
- **每次保存都是新版本**：右侧「版本历史」能看到每一次改动，还能和当前版本做行级对比、一键回滚到任一旧版。
- **变更说明**：保存时填一句"改了啥"，方便同事事后追溯。

> 【提示】编辑保存的是富文本，但系统底层会自动生成纯文本用于**检索与 AI 问答**，所以你贴的图片不影响别人搜得到正文内容。

### 协作防冲突：编辑锁（自动）
- 你点「编辑」进入页面时，系统会**自动帮你占住这篇文档**（编辑锁）。这期间别人进入同一篇会看到「只读预览」并提示"谁正在编辑"，避免两人同时改、互相覆盖。
- 你**保存**或**关掉页面**时锁会自动释放；万一电脑死机/断网，锁会在 5 分钟后自动过期，同事就能接着编辑。
- 若提示"XXX 正在编辑本文档"，说明对方正在改，请稍后再试或先联系对方。

### 一键导出：Word / PDF
- 文档详情页右上角有「导出 Word」和「导出 PDF」两个按钮，点一下即可下载：
  - **导出 Word**：还原标题/段落/列表/表格/引用/图片/链接，可直接用 Office 或 WPS 继续改。
  - **导出 PDF**：生成排版清晰的 PDF（中文不乱码），适合正式分发或打印。
- 没有权限看到这篇文档的人，导出也会被拒绝（不泄漏内容）。

## 七-三、设置"谁能看这篇文档"（私有 / 指定人，文档级权限）

默认情况下文档按"部门 + 密级"规则可见。如果你想让某篇文档**只给特定的人看**，或设为**私有**，用详情页右上角的「🔐 可见权限」面板：

- **可见模式**：选「继承（默认）」走全局规则；选「受限（私有）」则只有你下面授权的人能看到。
- **添加授权**：点「添加」，选「用户」或「角色」，再选具体人或角色，权限选「仅查看」或「可查看并可编辑」。
- **生效**：保存后，未授权的人（**包括同部门的其他人**）都看不到这篇文档，只有你授权的对象能打开。
- **谁能设**：只有文档**创建人**或**管理员**能改这个设置；别人改会被拒绝。
- **撤销**：把模式改回「继承」即可恢复按全局规则可见。

> 【举例】一份只给"财务二部"看的报价分析，设为「受限」并授权财务二部角色「仅查看」，采购一部的人就搜不到也打不开它了。

## 八、四级密级怎么选？（上传时必看）

| 密级 | 含义 | 谁能看 |
| --- | --- | --- |
| **公开** | 外部也能看、无敏感信息 | 所有人 |
| **内部** | 公司内部通用，不含敏感经营数据 | 公司内同事 |
| **机密** | 含经营、客户、合同等敏感信息 | 仅被授权的同事 |

> 【重要】密级**宁低勿高、如实填写**。把机密资料标成"内部"会泄密，把普通资料标成"机密"会影响别人使用。拿不准时问部门负责人或管理员。

## 九、六大知识域怎么分？（一级分类说明）

上传时选"一级分类"，对应公司知识的六大块：

| 编码 | 名称 | 放什么 |
| --- | --- | --- |
| POLICY | 政策法规库 | 国家/地方/行业的政策、法规、合规要求 |
| PROJECT | 项目知识库 | 项目方案、立项、进度、复盘 |
| CUSTOMER | 客户与市场 | 客户画像、市场洞察、竞品 |
| PRODUCT | 产品与技术 | 产品文档、技术方案、接口说明 |
| PROCESS | 制度与流程 | 公司制度、审批流、操作 SOP |
| TRAINING | 培训与沉淀 | 培训材料、经验总结、方法论 |

> 【提示】分错类没关系，审核员或管理员可以调整；但尽量选准，方便别人检索。

## 十、第四步：审核知识（审核员专属）

> 本页只有**审核员 / 管理员**能看到。

### 操作步骤

1. 点顶部导航 **「审核台」**。
2. 列表里是全部**「待审核」**的文档。
3. 点某条进去看内容和元数据，判断：
   - 内容是否准确、无违规？
   - 密级、分类是否合适？
   - 命名、来源是否规范？
4. 两种操作：
   - **通过 → 发布**：文档立刻对有权限的人可见。
   - **退回**：必须填写**退回原因**（如"缺来源，请补充"），提交后文档状态变"已退回"，上传人会收到原因去修改。

> 【提示】审核是对全公司知识质量负责，宁可慢一点也要看仔细。发现敏感信息标错密级的，退回并要求改正。

## 十一、第五步：看效能看板（了解平台使用情况）

点顶部导航 **「效能看板」**，一眼看到平台健康度：

- **知识总量**：一共存了多少份文档、被切成了多少条知识碎片（碎片越多，检索越细）。
- **状态分布**：已发布 / 待审核 / 已退回 各占多少。
- **最近 30 天检索统计**：大家搜了多少次、命中率怎么样。

> 【提示】待审核堆积很多，说明审核人力不够；命中率持续偏低，说明该补充资料或优化检索了。看板是给管理决策用的。

## 十二、管理后台（管理员专属）

点顶部导航 **「管理后台」**，里面有六个标签页：

| 标签页 | 干什么 |
| --- | --- |
| **用户** | 新增同事账号、重置密码、启用/停用账号 |
| **API 密钥** | 生成程序调用用的密钥（给其他系统对接用），可随时吊销 |
| **审计日志** | 查看谁在什么时候做了什么（只记录、不可删），可导出 CSV |
| **检索评测** | 跑一轮"准确率考试"，验证 AI 检索是否达标（目标 Recall@5 ≥ 90%） |
| **索引** | 资料异常时，点"重建索引"重新生成检索数据 |
| **配置** | 查看并测试大模型（LLM）/向量（Embedding）连通性 |

> 【注意】审计日志**任何人不能删除或修改**，这是合规要求。如果发现异常操作，从这里追。

## 十三、常见问题（FAQ）

**Q1：我搜不到某份资料，是系统坏了吗？**
先确认：① 是不是筛选项（分类/密级）设太窄；② 这份资料是否已"已发布"（待审核/已退回的别人看不到）；③ 密级是不是"机密"而你没权限。都不是的话，换关键词或同义词再试。

**Q2：AI 回答"没找到相关信息"怎么办？**
说明资料库里还没有对应内容。你可以：① 去「知识入库」把相关文档传上来；② 换个更通用的问法。AI 不会凭空编答案。

**Q3：上传后多久能搜到？**
正常几秒到一分钟（取决于文档大小和服务器负载）。如果一直"解析中"，找管理员在「管理后台-索引」点"重建索引"。

**Q4：PDF 传上去搜不到内容？**
大概率是**扫描版图片 PDF**，系统提取不出文字。请用可复制文字的 PDF，或先转成 Word/txt 再传。

**Q5：我传错了/想改资料？**
已发布的文档不能直接改。联系管理员下架（「已下架」）后重新上传，或让管理员在后台调整元数据。

**Q6：忘记密码了？**
普通用户找管理员重置；管理员自己忘记且无人可重置时，需由部署人员重置数据库，请提前保管好初始密码并及时修改。

**Q7：机密资料会不会泄露给没权限的人？**
不会。系统在数据层就做了权限过滤，无权限的人检索和问答都看不到机密内容，且所有访问都有审计记录。

## 十四、安全与规范提醒（请务必看）

1. **账号不共用**：每人用自己的账号登录，方便追溯操作。
2. **密码要改**：初始密码 `Admin@123456` 首次登录会强制改；平时在「🔑 修改密码」页自助修改。密码需 ≥8 位且含字母+数字。
3. **密级如实填**：见第九节，机密资料严禁标低。
4. **来源可追溯**：上传资料尽量填"来源"，保证每句话都能追到出处。
5. **AI 答案以原文为准**：关键决策回到原始文档确认，别只信 AI。
6. **不外传平台内容**：内部/机密资料禁止截图外发到公司外部。
7. **可选开启 MFA**：接触机密内容的同事，建议在「🔐 我的安全」页扫码开通多因子认证（登录需动态码），更安全。
8. **发现问题及时报**：检索异常、答案明显错误、权限不对，立刻找管理员。
