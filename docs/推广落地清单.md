# AI-KM 推广落地清单

> 目的：把已具备生产能力的 AI-KM 知识库，稳妥地推到业务团队真正用起来。
> 思路：先立规范与试点，再培训与扩面，最后固化到日常工作流。

---

## 阶段一：推广前准备（地基）

- [ ] **账号与部门体系就位**
  - 管理员在「管理后台」按公司组织架构建立部门（如：采购一部、市场部、知识管理中心）
  - 按角色建账号：管理员 / 知识审核员 / 知识贡献者 / 普通用户
  - 密码策略已生效（≥8 位、字母+数字），强制首登改密
- [ ] **分类与入库规范宣贯**
  - 全员知悉《知识分类标准与入库规范》：六大一级、三级密级、质量等级
  - 明确"谁能看什么"：密级 + 部门隔离规则（避免误发机密）
- [ ] **示范内容填充**
  - 由信息/知识管理员先入库 10~20 篇高质量标杆文档（政策、SOP、项目复盘等）
  - 对标杆文档标记 `verified`（已验证），让检索排序优先、树立质量标杆
- [ ] **MFA 倡导**（可选但建议）
  - 对接触机密内容的账号，倡导在「🔐 我的安全」开通 MFA

## 阶段二：试点（小范围验证）

- [ ] 选 **1~2 个试点部门**（建议选知识产出频繁、配合度高的团队，如采购执行 + 项目）
- [ ] 试点期 2 周，每日收集：检索命中率、问答可用性、入库卡点
- [ ] 跑一次《测试报告》式冒烟（`scripts/seed_demo.py` 做权限断言），确认隔离无误
- [ ] 试点复盘会：哪些场景真有用、哪些流程卡、哪些内容缺

## 阶段三：培训（让人会用）

- [ ] 准备培训材料（基于《用户使用指南》）：
  - 3 分钟速览：检索、AI 问答、知识入库
  - 5 分钟实操：上传一篇文档 → 审核发布 → 被检索到 → 问 AI 拿到带引用的答案
  - 安全须知：密级怎么选、机密内容谁能看、密码与 MFA
- [ ] 组织一场实操培训（带真实问题现场练），参考 AI 生产力重构培训打法
- [ ] 输出「一页速查卡」贴在团队空间

## 阶段四：扩面与固化

- [ ] 向全公司开放，纳入新员工入职知识库指引
- [ ] 把"重要知识先入 AI-KM 再发群"写成协作规范
- [ ] 设定内容复审周期（规范第八章：政策 90 天、项目/客户 180 天、制度/培训 365 天）
- [ ] 每月看板回顾：入库量、检索量、问答量、低质量待提质清单

## 上线前最终检查（Go-Live Checklist）

- [ ] 服务 `healthy`（`docker compose ps`）
- [ ] 管理员已改默认密码
- [ ] `AIKM_SECRET_KEY` 为强随机值且已固定
- [ ] 数据卷已做首次备份
- [ ] HTTPS / Nginx 反代已配（或在可信局域网纯 HTTP 已评估风险）
- [ ] 已告知全员：默认账号、改密、密级规范、MFA 可选
- [ ] 备案一个应急联系人（平台管理员）

---

## 推广话术（给业务同事）

> "以后找制度、找政策、找项目经验，先问 AI-KM：检索秒级命中，问答带原文出处可溯源；
> 自己写的交付物、复盘、SOP，顺手入到知识库，下次别人就能直接问到，团队资产不随人走。"
