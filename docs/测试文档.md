## 1. 测试策略

采用**分层 + 自动化**策略，所有用例以 Python 脚本（`scripts/_verify_*.py`）实现，可重复运行、可纳入 CI。

| 层级 | 手段 | 目标 |
|---|---|---|
| 单元/集成 | 直接调用业务函数（auth/db/ingest/search/rag） | 验证单模块正确性 |
| 接口 | Flask `test_client()` 模拟 HTTP | 验证路由/鉴权/信封/权限隔离 |
| 端到端 | 串联登录→检索→问答→入库→审核→导出 | 验证跨模块主流程 |
| 回归 | 全量套件一键运行 | 任何改动后"零回归" |
| 冒烟 | 真实 Docker 容器探活 + 关键链路 | 验证可部署性 |

设计原则：**权限隔离用真实多角色账号断言**（非 mock），**降级路径必须覆盖**（向量失败→BM25 仍可用），**升级路径必须验证**（老库迁移不崩）。

## 4. 验证脚本说明

| 脚本 | 内容 | 项数 |
|---|---|---|
| `scripts/_verify_p01_links.py` | P1 标签体系 + 交叉引用 [[…]] + 段落锚点直达 | 25 |
| `scripts/_verify_p01_extra.py` | P1 导出（md）、页面级评论、审计页 | 36 |
| `scripts/_verify_p02_version.py` | P0-2 文档版本历史/回滚、RAG 拒答、检索质量加权 | 26 |
| `scripts/_verify_p02.py` | P2 MFA(TOTP) 全链路、SSO 优雅降级、REST v1、diagrams.net 存取 | 48 |
| `scripts/_verify_richtext.py` | 富文本编辑器（Quill）入库/保存/版本兼容/图片上传 | 25 |
| `scripts/_verify_complete.py` | **P 完整版三项补齐**：并发编辑锁 / Docx+PDF 导出 / 文档级 ACL | 23 |
| `scripts/seed_demo.py` | 示例数据幂等灌入 + 老库升级冒烟 + 权限隔离断言 | — |
| `scripts/import_eval.py` / `run_eval.py` | 评测集导入与跑分（独立） | — |

运行：
```bash
PY=python   # 指向已装依赖的解释器
for s in _verify_p01_links _verify_p01_extra _verify_p02_version _verify_p02 _verify_richtext _verify_complete; do
  $PY scripts/$s.py 2>&1 | tail -3
done
$PY scripts/seed_demo.py   # 升级+冒烟
```

每个脚本内部以 `check(name, condition, detail)` 累计 PASS/FAIL，结尾打印 `共 N 项，通过 M，失败 K`，全 0 失败即通过。

## 5. 关键测试用例（节选）

### 5.1 权限隔离（核心安全，6 账号断言）
规则：`可见 = 已发布 ∩ 密级≤许可 ∩ (本部门 ∪ 公开 ∪ 跨部门)`。
| 账号 | 角色 | 预期可见 | 断言 |
|---|---|---|---|
| admin_demo | 管理员 | 13 | 全可见 ✅ |
| reviewer_demo | 审核员 | 10 | 本部门+机密，跨部不可见 ✅ |
| contributor_demo | 贡献者 | 9 | 本部门+内部 ✅ |
| user_demo | 普通 | 7 | 本部门市场部+内部 ✅ |
| user_conf_demo | 普通(可机密) | 8 | +机密 ✅ |
| user_cross_demo | 普通(跨部门) | 11 | +跨部门 ✅ |

### 5.2 安全加固
- 登录失败 5 次 → 第 6 次返回 429（限流生效）。
- 弱密码（`abc`）创建/改密被拒，提示"字母+数字"。
- 未配 `SECRET_KEY` → 临时随机并启动告警；`/login` 响应含 CSP/X-Frame-Options 等安全头。
- `/api/v1/health` 无需鉴权（探活）；其余 v1 端点无 Key 返回 401。

### 5.3 入库与生命周期
- 缺必填项（标题/分类/部门/密级/责任人）→ 拒绝并给出具体字段提示。
- 正文 < 200 字 → 触碰红线拒绝。
- 重复内容（同 content_hash）→ 拒绝并指向已有文档。
- 在线编辑 → 版本号 +1 且旧版本入 `doc_versions`；回滚 → 重建切片与向量。

### 5.4 检索与 RAG
- 中文查询"集采"召回政策文档；混合模式结果优于单路。
- 库外问题 → 明确拒答（`NO_ANSWER_TEXT`），不编造。
- 引用 draft 知识 → 标注"未验证"。
- 向量失败（无密钥）→ 自动降级 BM25，检索仍可用。

### 5.5 P2
- MFA：开通生成密钥+二维码+8 备用码；动态码/备用码均可登录；关闭需验密码。
- SSO：缺 ldap3/requests → 应用照常启动、LDAP 路由优雅降级。
- REST v1：文档列表过滤+分页、`/search` 三模式、详情含 tags/引用/chunks、`/openapi.json` 可下载。
- diagrams.net：图 XML 存 `doc_diagrams`，编辑/只读双模式读取正确。

### 5.6 完整版三项补齐（并发编辑锁 / 导出 / ACL，各端点断言）
- **编辑锁**：本人抢占 200；他人（管理员）抢占被拒 409 + 对方姓名；保存后锁释放；TTL 过期后他人可抢占；无编辑权拿锁 403。
- **导出**：Docx 返回合法 ZIP（`PK`）、PDF 返回 `%PDF`、Markdown 回归可用、纯文本兜底不崩、无权限者导出 404。
- **ACL**：restricted + 授权 user 仅其可见；未授权（含同部门未授权）不可见 404；创建人/管理员恒可见；列表过滤与详情一致；`view_edit` 授权者可编辑；非创建人设 ACL 被拒 403；改回 inherit 成功。

## 7. 已知限制与风险（测试覆盖边界）

| 限制 | 说明 | 缓解 |
|---|---|---|
| SSO 未接真实 IdP | 仅验证"缺依赖优雅降级 + 逻辑可达"，未跑通真实 LDAP/OIDC 登录 | 提供 IdP 配置后跑真实联调 |
| diagrams.net 编辑 UI | 需联网加载 embed.diagrams.net，内网离线界面空白（图仍能存库） | 自托管 embed 或放开公网 CDN |
| 向量检索需密钥 | 无有效 Embedding 密钥时仅 BM25（语义能力降级） | 配置 SiliconFlow/Ollama |
| 限流为进程内 | 当前 gunicorn 单 worker 足够；多实例需换 Redis | NFR-4 预留 |
| 性能压测 | P95<1.5s 为设计指标，未在万级文档规模做正式压测 | 上线后用 search_logs 统计验证 |
